MY PROJECTS

Throughout my Computer Science journey, I discovered that my interest in technology extends beyond just writing code. While web development sparked my passion for creating practical solutions, I also became fascinated by how data can uncover meaningful insights and how digital evidence can be analysed to solve cyber-related investigations. These experiences allowed me to explore three different areas of Computer Science—Web Development, Big Data Analytics, and Digital Forensics—each strengthening a different set of technical and problem-solving skills.

Web Development Projects

Building web applications has always been my primary interest. Throughout my degree, I developed several full-stack applications using PHP, MySQL, HTML, CSS, and JavaScript. My projects focused on creating secure, user-friendly systems with role-based authentication, database management, and responsive interfaces.

Highlighted Projects:

EduTrackUPNM - A Final Year Project that streamlines student application management through role-based access control and automated CRUD operations.

E-Library ALK - A digital library management system featuring customized dashboards, real-time tracking, and centralized data management for cadets and instructors.

Big Data Analytics Projects

As I explored data science, I learned how raw data can be transformed into valuable insights. Using Python and the CRISP-DM methodology, I worked with datasets containing over 1,000 records, performing data cleaning, preprocessing, statistical analysis, and visualization to support data-driven decision-making.

Digital Forensics Projects

My curiosity about cybersecurity led me to digital forensics, where I learned how to investigate and analyse digital evidence. I worked on verifying file integrity using MD5 and SHA-256 hashing, extracting EXIF metadata, and examining hexadecimal data with HxD to recover and analyse hidden or corrupted digital artifacts.
